# Singly Linked List: Insert Head

## Approach

- Inserting at the heada means adding a new node to the very beginning of the list, making it the new first node.
- This is an important operation because it's the one place we can always insert in `O(1)`.
- Make sure to wire the new node to t he existing list before updating `head`; if you update `head` first, you lose your reference to the rest of the list.

## High-Level Algorithm

1. Create a new node with the given value.
2. If the list was empty, also set `tail` to the new node.
    - A single node is both `head` and `tail`.
3. Set the new node's `next` pointer to the current head.
    - This connects the new node to the existing list.
4. Update `head` to point to the new node.
    - The new node is now the first node.
5. Increment `length` by 1.

## Implementation

```javascript
insertHead(value) {
	const newNode = new Node(value); // Create the new node

	if(!this.head) {
		// If the list is empty, the new node is both head and tail.
		this.head = newNode;
		this.tail = newNode;
	} else {
		newNode.next = this.head; // Point new node to the current head
		this.head = newNode; // Update head to the new node
	}
	
	this.length++; // Increment length
}
```
- Time complexity: `O(1)`
    - No traversal required.
- Space complexity: `O(1)`
    - We allocate exactly one new node regardless of the list size.
