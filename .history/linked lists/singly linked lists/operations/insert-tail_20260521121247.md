# Singly Linked List: Insert Tail

## Approach

- Inserting at the tail means adding a new node to the very end of the list, making it the new last node.
- Because we're tracking `this.tail`, we can do this in `O(1)` - we already have a direct reference to the last node, so we just wire the new node onto the end and update `tail`.
    - Without a `tail` pointer, we'd have to traverse the list to find the last node, which would be an `O(n)` operation, which is why it's worth it to track `tail`.

## High-Level Algorithm

1. Create a new node with the given data.
2. If the list is empty, set both the head and the tail to the new node.
3. Otherwise:
    1. Set the current tail's `next` to point to the new node.
        - Connects the existing list to the new node.
    2. Update `tail` to point to the new node.
        - Makes the new node the last node.
4. Increment length by 1.
