# Singly Linked List: Reverse

# Approach

---

- Reversing a singly linked list means flipping the direction of every next pointer so that the tail becomes the new head, and the head becomes the new tail; every node that previously pointed forward now points backward.
- Core challenge: When you reverse a node’s `next` pointer, you immediately lose your reference to the rest of the list. To solve this, we use **three pointers** that traverse together through the list:
    - `prev` - the node behind `current` (starts as `null`)
    - `current` - the node weren’t currently reversing
    - `next` - the node ahead of `current` (saved before we break the link)

# High-level Algorithm

---

1. If the list is empty or has one node, no reversal needed - return.
2. Initialize three pointers:
    - `prev = null`
    - `current = head`
    - `next = null`
3. Update `tail` to the original `head`
4. While `current` is not `null`:
    1. Save [`current.next`](http://current.next) in `next` (preserve the forward reference)
    2. Reverse current’s pointer: `current.next = prev`
    3. Advance `prev` to `current`
    4. Advance `current` to `next`
5. Update `head` to `prev` (which is now the last node we processed - the new head).

# Implementation

---

```jsx
reverse() {
	// No reversal needed for empty or single-node lists
	if(!this.head || this.head === this.tail) {
		return;
	}
	
	// Initialize three pointers
	let prev = null;
	let current = this.head;
	let next = null;
	
	// Update tail to the original head
	this.tail = this.head;
	
	// Walk through the list, reversing each pointer
	while(current !== null) {
		next = current.next;
		current.next = prev;
		prev = current;
		current = next;
	}
	// When the loop ends, prev is sitting on the last node (the new head)
	
	// Update head to the new fist node
	this.head = prev;
}
```

- Time complexity: `O(n)`
- Space complexity: `O(1)`
