# Singly Linked List: Search

## Approach

- Searching means finding whether a given value exists in a list, and if so, returning its position (index).
- Since linked lists have no index-based access, we must traverse the list until we find the target node by comparing the current node’s value with the target value.
- Two common variations:
    1. **Search by value** - Return the index of the first node with a matching value; or -1 if not found.
    2. **Search by index** - Return the value of the node at a given index, or null if out of bounds.

## High-level Algorithms

### Search by Value

1. If the list is empty, return `-1`.
2. Traverse list, tracking position with `index`. While `current` is not `null`:
    1. If `current.value` matches the target, return `index`; we've found the value.
    2. Move `current` forward.
    3. Increment `index`.
3. If we exit the loop without finding the value, return `-1`.

### Search by Index

1. If `index` is out of bounds (less than 0 or ≥ length), return `null`.
2. Start at head with `counter = 0`.
3. While `counter` is less than the target index:
    1. Move `current` forward.
    2. Increment `counter`.
4. Return `current.value`.

## Implementations

### Search by Value

```jsx
searchByValue(value) {
	// If the list is empty, value cannot exist
	if(!this.head) {
		return -1;
	}
	
	// Traverse list, track position with index
	let current = this.head;
	let index = 0;
	
	while(current !== null) {
		if(current.value === value) {
			return index;
		}
		
		current = current.next;
		index++;
	}
    
	return -1;
}
```

### Search by Index

```jsx
searchByIndex(index) {
	if(index < 0 || index >= this.length) return null;
	
	let current = this.head;
	let counter = 0;
	
	while(counter < index) {
		current = current.next;
		counter++;
	}
	
	return current.value;
}
```

- Time complexity: `O(n)`
- Space complexity: `O(1)`
