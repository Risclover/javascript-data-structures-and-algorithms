# Singly Linked List: Traversal

## Approach

- **Traversal** means visiting every node in the list, one by one, from head to tail.
- Since we have no index-based access, we must start at the head and follow the `next` pointers until we reach a node where `next` is `null` - this is the tail, signaling the end of the list.
- Traversal is the foundation of almost every other linked list operation; they rely on this same basic walking pattern.

## High-Level Algorithm

1. Start with a pointer `current` set to the list's `head`.
2. While `current` is not `null`:
    a. Do something with `current.value` (print it, check it, etc.)
    b. Move `current` forward: `curent = current.next`.
