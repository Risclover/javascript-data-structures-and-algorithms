# SLL Interview Problems: Find Middle Node

Given a singly linked list, return the middle node. If the list has an even number of nodes, return the second middle node.

## Approaches

### Naive Approach

- Traverse the entire list to get its length
- Divide its length by two
- Traverse again to that index

Although this works, it is not the most efficient solution; it requires two full passes through the list, and we can do it in one pass using two pointers.

### Fast & Slow Pointer Technique (also called Tortoise and Hare)

- Use two pointers, `slow` and `fast`, both starting at the head.
- On every iteration, `slow` moves forward one step, and `fast`, two steps.
- Because `fast` is twice as fast as `slow`, by the time `fast` reaches the end, `slow` is at the exact middle.

The solution below uses this two pointer approach.

## High-level Algorithm

1. If the list is empty, return `null`.
2. Initialize both `slow` and `fast` pointers to the head.
3. While `fast` is not `null` AND `fast.next` is not `null`:
    1. Move `slow` one step forward
    2. Move `fast` two steps forward
4. When the loop ends, `slow` is at the middle node - return it.

## Implementation

```jsx
function findMiddle(head) {
    // List is empty
	if(!head) {
		return null;
	}
	
    // Fast and slow pointers, starting at the head
	let slow = head;
	let fast = head;
	
    // Every time slow moves forward once, fast moves forward twice.
	while (fast !== null && fast.next !== null) {
		slow = slow.next;
		fast = fast.next.next;
	}
	
    // Slow is now at the middle node. Return.
	return slow;
}
```

- Time complexity: `O(n)`
- Space complexity: `O(1)`
