# Singly Linked List: Delete Head
[Back to Singly Linked Lists](../singly-linked-lists.md)

## Approach

- Deleting the head means removing the first node from the list and making the second node the new head.
- `O(1)` operation, since no traversal needed.
- The key is to advance `head` forward to the second node, effectively orphaning the old head node and allowing the JavaScript garbage collector to clean it up.
- We need to handle two edge cases:
    1. If the list is empty, there’s nothing to delete.
    2. If the list has only one node, after deletion both `head` and `tail` must be set to `null`.

## High-level Algorithm

1. If the list is empty, return null - nothing to delete.
2. Store a reference to the current head node (to return its value).
3. Advance `head` to `head.next`
    - The second node is now the first node
4. If the list is now empty (`head` is `null`), also set `tail` to `null`.
    - This means the list only had one node, and now it’s completely empty.
5. Decrement length by 1.
6. Return the original head’s value.

## Implementation

```jsx
deleteHead() {
	// If the list is empty, there's nothing to delete.
	if(!this.head) {
		return null;
	}
	
	// STore a reference to the current head
	const deletedNode = this.head;
	
	// Advance head to the next node
	this.head = this.head.next;
	
	// If the list is now empty, update tail to null
	if(!this.head) {
		this.tail = null;
	}
	
	// Decrement length
	this.length--;
	
	// Return the original head's value
	return deletedNode.value;
}
```

- Time complexity: `O(1)`
- Space complexity: `O(1)`
