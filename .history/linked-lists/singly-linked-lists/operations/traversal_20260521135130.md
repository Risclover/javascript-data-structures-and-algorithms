# Singly Linked List: Traversal



## Approach

- **Traversal** means visiting every node in the list, one by one, from head to tail.
- Since we have no index-based access, we must start at the head and follow the `next` pointers until we reach a node where `next` is `null` - this is the tail, signaling the end of the list.
- Traversal is the foundation of almost every other linked list operation; they rely on this same basic walking pattern.

## High-Level Algorithm

1. Start with a pointer `current` set to the list's `head`.
2. While `current` is not `null`:
    1. Do something with `current.value` (print it, check it, etc.)
    2. Move `current` forward: `curent = current.next`.
3. When `current` is `null`, we've passed the tail, so we stop.

**Note**: The variable `current` is a **temporary pointer** that walks the list. Note that we never move `head` itself, as that would permanently lose our reference to the start of the list. We always create a separate pointer to do the walking.

## Implementation

```javascript
class LinkedList {
	constructor() {
		this.head = null;
		this.tail = null;
		this.length = 0;
	}
	
	traverse() {
		// If the list is empty, there's nothing to traverse
		if(!this.head) {
			return;
		}
		
		let current = this.head; // Start at the head
		
		while (current !== null) {
			console.log(current.value); // Do something with the current node's value
			current = current.next; // Move the pointer forward to the next node
		}
	}
}
```
* Time complexity: `O(n)`
* Space complexity: `O(1)`
    * We only create one extra variable, `current`.
    * It doesn't matter how long the list is; we never allocate additional memory proportional to `n`. That single pointer is all that is needed.
